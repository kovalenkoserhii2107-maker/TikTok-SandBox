# Kaboom Sandbox

Физическая песочница 2.5D в браузере в духе Melon Playground / People Playground.
Ставишь персонажей, оружие, взрывчатку и технику и смотришь, что из этого выйдет.
Игра — PWA: устанавливается на Android и iOS как приложение с иконкой и работает без интернета.

## Что есть

**Персонажи** — активные рэгдоллы с мышцами и равновесием: стоят, ходят, падают и встают.
Есть ранения, кровотечение, переломы, отрубание конечностей и потеря сознания.

| Персонаж | Особенности |
|---|---|
| Человек | Чувствует боль, истекает кровью, убегает от зомби |
| Солдат | Каска и бронежилет ослабляют пули. С оружием в руках сам стреляет по зомби и не стреляет, если на линии огня мирный |
| Зомби | Не чувствует боли, умирает только от урона в голову. Идёт к людям, кусает и заражает — укушенный через несколько секунд превращается в зомби |
| Робот | Стальной корпус, искры и масло вместо крови, очень прочный, при гибели взрывается |
| Гигант | В 1,5 раза выше, в 3 раза тяжелее и крепче |
| Скелет | Лёгкий, кости отлетают от ударов, живёт, пока цел череп |
| Манекен | Краш-тест манекен: бессмертный, без мышц |

**Оружие**: пистолет, револьвер, автомат АК, пистолет-пулемёт, дробовик, винчестер, снайперская винтовка (пробивает несколько тел), миниган, ракетница РПГ.
Пули — лучи с пробитием материалов, отдачей, гильзами и трассерами.

**Холодное оружие**: нож (втыкается, если бросить остриём), катана (отрубает конечности), топор, копьё, бита, кувалда.

**Взрывчатка**: граната (осколки), динамит, мина, C4 (прилипает, взрыв кнопкой «Детонатор»), взрывоопасная бочка, авиабомба, ядерная бомба (вспышка, ударная волна, ядерный гриб, обратная тяга воздуха).
Взрывы учитывают укрытия и вызывают цепные реакции.

**Техника**: грузовик (возит людей в кузове), легковушка, танк (пушка, пулемёт, наводка ствола, гусеницы). Колёса на подвеске, техника горит и взрывается.

**Предметы**: ящики (ломаются на доски), контейнер, бочка, бетон, кирпич, доска, балка, стекло (бьётся), арбуз, мяч, покрышка, неподвижная платформа.

**Инструменты**: рука (тянуть, бросать, вращать вторым пальцем, короткое нажатие — активировать), заморозка, верёвка, сварка, лечение (пришивает конечности обратно), удаление.

**Замедление времени**: 0.5×, 0.25×, 0.1×, 0.03× — звук тоже замедляется.

**Миры**: город, ночной город, пустыня, Луна (гравитация 1,62 м/с²), испытательный полигон, зимний лес.
Миры можно менять, не очищая сцену.

**2.5D**: физика плоская (Box2D), но каждый объект нарисован как объёмное тело в настоящей перспективе.
Фон и земля уходят вглубь сцены, поэтому параллакс получается сам собой.

## Как запустить

Нужен любой статический HTTP-сервер (service worker не работает с `file://`):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Публикация через GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В **Source** выберите **Deploy from a branch**, ветку `main` (или рабочую ветку) и папку `/ (root)`.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.

## Установка на телефон

- **Android (Chrome)**: при открытии игра сама предложит «Установить». Или меню ⋮ → «Установить приложение».
- **iPhone / iPad (Safari)**: «Поделиться» → «На экран „Домой“» → «Добавить». Подсказка показывается прямо в игре.

## Управление на ПК

Пробел — пауза, `T` — замедление, `1`–`6` — инструменты, стрелки или `A`/`D` — езда, `W`/`S` — ствол танка,
`F` — пушка, `G` — пулемёт, `Q`/`E` или Shift + колесо — вращать взятый объект, колесо — масштаб.

## Технологии

Чистый JavaScript (ES-модули) и Canvas 2D, физика — [planck.js](https://github.com/piqnt/planck.js) (порт Box2D, лицензия MIT, лежит в `js/lib`).
Звуки синтезируются через WebAudio, внешних файлов нет. Сборка не нужна.

```
index.html           разметка интерфейса
css/style.css        стили
js/main.js           игровой цикл, камера, инструменты
js/sim.js            физика, пули, взрывы
js/render.js         2.5D-рендер
js/effects.js        частицы, кровь, дым, ядерный гриб
js/worlds.js         миры
js/entities/*.js     персонажи, оружие, взрывчатка, техника, предметы
sw.js                офлайн-кэш (при обновлении меняйте VERSION)
```
